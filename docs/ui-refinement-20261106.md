## 预设与兼容

- 增加 `image.nai.generationPresets`、`activePresetId`、`autoResolution`、`aspect`。命名预设只保存生成参数，不包含地址、密钥和启用状态。
- 选择预设将其参数复制到当前草稿；编辑同步更新该预设的草稿，保存后写盘。刷新和重启后保留选择。
- V5/4.5 的提示词仍按模型族独立保存；页面只呈现当前模型对应的提示词编辑器，切换不会覆盖另一族。
- 旧配置未开启自动分辨率时保留原始宽高。选择比例后采用现有 64 像素网格尺寸。开启自动分辨率后，正式请求与 dry-run 使用相同的约百万像素计算结果。
- 官方连接空地址归一为官方服务地址；非官方仍要求用户填写地址。现有功能开关、密钥只写和显式测试规则保持有效。

## 第二轮反馈

- 连接与工具使用插头、媒体能力使用图片图标；侧栏新增「QQ 连接」，可内联 NapCat / SnowLuma。未配置时不猜测服务地址；部署时 DSH 必须先询问用户，配置文件保留在忽略目录中。
- OpenAI-compatible 显示 GPT Image 支持说明；Banana 类模型需要服务商提供兼容接口。
- NAI 正向与反向官方预设改为模型对应的等级下拉，位于画师串和用户反向提示词之前。默认只有「默认预设」，用户自建的命名预设仍可保存切换。官方词表来自 [Quality Tags](https://docs.novelai.net/en/image/qualitytags/) 和 [Undesired Content](https://docs.novelai.net/en/image/undesiredcontent/)。旧版自定义预设保留兼容模式。
- 开关统一为 42px 高的点击区，保持固定文案，切换不会因文字变化而移位；语音服务选择即设置该后端启用，移除后端内部重复复选框。
- Breeze / GPT-SoVITS 参考音频增加文件选择；说明改为「音频里说的话」。GPT-SoVITS 输出保持 WAV，移除输出格式下拉。[原生接口](https://github.com/RVC-Boss/GPT-SoVITS/blob/main/api_v2.py) 读取服务端路径，因此跨机器上传由可选的参考音频桥接服务处理，详见 `sidecars/reference-audio-bridge/README.md`。
- 识图改名「本地识图」；首页健康区移入右栏；QQ 状态读取实际连接遥测，过期或缺失时显示未知。
- 运行状态新增真实后台日志尾部、筛选、刷新和暂停，显示前脱敏；设置页运行库控制置顶，记忆配置按分组双列排列，删除实现细节注释。

## 第三轮反馈

- 自动分辨率改成 224×50px 的状态按钮；像素说明移入 i 提示。所有共用多行输入框限制高度 320px，超出后内部滚动。
- 正向、反向预设标题删除「官方」；选项使用 None / Standard / Light / Heavy / Human Focus / Furry Focus 等英文名称。画师串与反向提示词旁的 i 显示当前模型、当前等级实际使用的标签，切换模型或等级后同步更新。
- QQ 连接的第二种面板名称更正为 SnowLuma，保留旧配置标识兼容。增加启动与重启按钮；仅使用用户明确配置的本机程序，不从请求体接收命令。远端面板不提供本机进程控制。
- NapCat 带令牌的页面地址只在经过鉴权的响应中生成，令牌不回填设置表单、不写入源码。启动配置、进程记录、日志与运行库开关都留在 Git 忽略目录。重启前核验 PID、可执行文件、启动参数和可用的创建时间；不能确认时拒绝操作。
- Windows 使用短暂启动器拉起独立后台进程，防止 DSH 的进程树关闭操作连带结束 NapCat。仅点击启动/重启才操作进程；打开页面不会自动启动。

本机验证：构建与完整 verify 通过；新增启动器测试覆盖重复启动、重启、错误进程拒绝、令牌仅用于本机地址。浏览器已验证 50px 大按钮、320px 输入上限、模型/等级切换时标签同步和无横向溢出。持续终端 bundle 已在本机启用：Windows 运行终端服务、PowerShell 后端与工具，Bash 后端按宿主平台条件关闭。运行库、自主规划、心跳、分享候选四项已开启并重启，运行库数据已可读。本机服务选择和凭据没有发布到 Git。
