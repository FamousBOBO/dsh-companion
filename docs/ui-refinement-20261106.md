## 预设与兼容

- 增加 `image.nai.generationPresets`、`activePresetId`、`autoResolution`、`aspect`。命名预设只保存生成参数，不包含地址、密钥和启用状态。
- 选择预设将其参数复制到当前草稿；编辑同步更新该预设的草稿，保存后写盘。刷新和重启后保留选择。
- V5/4.5 的提示词仍按模型族独立保存；页面只呈现当前模型对应的提示词编辑器，切换不会覆盖另一族。
- 旧配置未开启自动分辨率时保留原始宽高。选择比例后采用现有 64 像素网格尺寸。开启自动分辨率后，正式请求与 dry-run 使用相同的约百万像素计算结果。
- 官方连接空地址归一为官方服务地址；非官方仍要求用户填写地址。现有功能开关、密钥只写和显式测试规则保持有效。

Windows + Node 24.14.0 + DSH 0.2.1-rc.3，隔离实例端口 3096。

- `npm ci`、`npm run build`、`npm run doctor`、`npm run setup`、实际宿主启动成功。
- `npm run verify -- --json`：8 个模块测试通过、1 个模块无测试；静态检查 28 项通过；宿主合成通过。
- 新增 6 个后端用例：命名预设磁盘回读、非法预设拒绝、三比例实际发包与 dry-run 一致、关闭自动尺寸时保持旧宽高。与配置 API 测试合跑 24/24。
- 实际浏览器操作创建两组参数不同的预设、保存、切换、刷新、宿主重启后回读成功；官方/非官方切换正确显示/隐藏地址。
- 1256×1244、2504×1244 下媒体内容没有横向滚动、输入框没有越过内容边界；识图位于末尾默认折叠；页面没有技术诊断入口。
